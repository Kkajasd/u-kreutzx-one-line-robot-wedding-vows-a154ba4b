One line of wedding vows for a robot couple: a classic vow ("in sickness and in health") with a machine-specific turn — low battery, airplane mode — and the payoff in the last few words: sharing the charger even at 1%. Written for make.fun's "One-Line Robot Wedding Vows" bounty, judged by an AI officiant in pairwise heats.

## Run it

```sh
node main.ts
```

The program writes the vow to `/output/entry.txt` (one line, 160 characters max).
